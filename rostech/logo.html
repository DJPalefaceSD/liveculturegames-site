Logo

Your own logo on the dash above the prompt, between your other bands.

HARD · CabinON TRACKv0.3.0tested on Claude Code 2.1.288
ON THE DASH
/logo set C:/path/to/logo.png
/logo set C:/path/to/logo.pngputs a PNG on the dash. A square logo with bold shapes reads best.
/logoshows which file is in use.
/logo hideand /logo show toggle it.
L1The logo is drawn in coloured block characters, two pixels to a character, so it shows in any terminal that can show colour.

Pictures are not needed.

L2For the sharpest logo, draw a small PNG for the dash yourself, 40 pixels a side or smaller.

A 16 by 16 PNG is a good size. A small PNG is drawn exactly as you drew it, one pixel to half a character, with nothing blurred.

L3A bigger PNG works too.

Its see-through border is trimmed, and it is shrunk to 16 by 16 pixels. Every pixel comes out either solid colour or clear, never a blur of the two, but thin lines can still break up at that size.

L4The PNG is read once when you set it, on your own machine with Windows PowerShell, and the result is kept across sessions in Claude Code's plugin store.

Nothing is sent anywhere. See-through parts of the PNG take your terminal's own colour.

L5Windows only for now, because reading the PNG uses PowerShell.
