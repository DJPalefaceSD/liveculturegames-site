Gas Gauge

A fuel gauge above the prompt: how much of your Claude plan is left, and when it refills.

SOFT · GaugesON TRACKv0.2.1tested on Claude Code 2.1.288
ON THE DASH
⛽ 5-hour  E ███ ½ █░░ F  71%  @ 3:40 PM
/gasprints every tank.
/gas hidemoves the numbers to the status line. /gas show brings the band back.
L1Read it like a car: E on the left, F on the right, the ½ mark in the middle.

Green above half a tank, yellow above a fifth, red below that.

L2Each gauge takes half the band.

A toast fires once when a tank drops past 25% left, and again past 10%.

L3The Tanks to show setting, in /config, picks which windows the gauge shows: both (the default), 5-hour alone, or week alone.

A tank it leaves out is gone everywhere, from the band, /gas, the warnings and the status line.

L4The numbers are the ones Claude Code itself reads off each response, so the gauge fills after Claude has answered once.

On an API key with no plan windows, it stays empty.

L5The band draws in the terminal and in the Code tab of the Claude desktop app.

The phone app does not draw it yet.
